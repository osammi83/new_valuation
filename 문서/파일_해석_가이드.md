# UP Valuation 파일 해석 가이드

작성일: 2026-04-20  
최종 업데이트: 2026-04-24  
버전: 1.3

이 문서는 현재 운영 코드 기준으로 파일별 역할, 읽는 순서, 실무 해석 포인트를 정리한 가이드다.

---

## 1) 먼저 보는 파일 순서 (실무 권장)

1. output/관심종목요약_YYYY-MM-DD.csv
2. output/진입후보요약_YYYY-MM-DD.csv
3. output/최종매수_전일비교_YYYY-MM-DD_vs_YYYY-MM-DD.csv
4. output/상세리포트_YYYY-MM-DD.csv

핵심:
- 빠른 판단은 watchlist/entry/diff
- 상세 검증은 valuation_report

```text
      up_column_dictionary_ko_YYYY-MM-DD.csv
```

## 3) 입력 데이터 파일 해석

### 3-1. universe.csv
- 역할: 일일 분석 대상 종목 목록
- 핵심 컬럼: name, ticker, market
- 운영 포인트: ticker는 항상 6자리 문자열

### 3-2. assumptions.csv
- 역할: 수동 가정치 저장
- 핵심 컬럼: target_pe_*, eps_growth_3y_pct, manual_forward_eps, max_position_pct, is_loss_making
- 운영 포인트: refresh_assumptions.py 실행 시 신규 ticker만 보강, 기존 수동값은 유지

### 3-3. eps_cache.csv
- 역할: EPS 관련 캐시
- 운영 포인트: 일일 실행은 캐시 우선 사용, 월간/격주 refresh_eps_cache.py로 갱신

## 4) output 파일 해석

### 4-1. 상세리포트_YYYY-MM-DD.csv (상세 원본)
- 전체 종목의 원천 분석 테이블
- 점수/지표/EPS 소스/액션/비중이 모두 포함됨
- 디버깅 및 심화 분석의 기준 파일

주요 해석 컬럼:
- total_score: 최종 순위 기준
- valuation_score / technical_score: 밸류/기술 분해 점수
- combined_action: 최종매수후보, 진입대기, 관찰, 제외
- eps_source_used: 모델에 실제 사용된 EPS 소스
- warn_flags: EPS없음, EPS스크랩 등 주의 플래그

### 4-2. 관심종목요약_YYYY-MM-DD.csv (일일 요약)
- 실무에서 가장 먼저 보는 파일
- 상위권 종목의 간단한 판단용

권장 확인 순서:
1. suggested_rank 상위 구간
2. combined_action 분포
3. brief_reason
4. warn_flags

### 4-3. 진입후보요약_YYYY-MM-DD.csv (진입 후보)
- 최종매수후보 + 진입대기만 모은 파일
- 종목 수가 watchlist보다 적어 집중 검토에 유리

### 4-4. 최종매수_30일타임라인_*.csv
- 당일 최종매수후보 종목별 최근 30거래일 흐름
- 핵심 컬럼:
  - close
  - prev20_high
  - breakout_20d_high
  - volume_ratio_20d

해석 포인트:
- breakout_20d_high의 1->0 전환은 순위 하락 원인이 될 수 있음
- volume_ratio_20d 급증/급감은 기술점수 변화와 직접 연관

주의:
- 당일 최종매수후보가 0개여도 파일은 빈 스키마로 생성됨(정상)

### 4-5. 최종매수_전일비교_*.csv
- 전일 대비 최종매수후보 변화 요약
- status: 유지/신규/이탈
- delta_total_score, delta_technical_score, delta_valuation_score로 원인 추적

권장 활용:
1. 이탈 종목의 delta_technical_score 확인
2. 신규 종목의 breakout/거래량 변화 확인
3. 유지 종목의 delta_rank와 점수 안정성 확인

## 5) 컬럼 사전 파일 위치 변경(중요)

현재 정책:
- 컬럼 사전은 output에 날짜별로 매일 생성하지 않음
- 문서 폴더 고정 파일로 관리

파일:
- 문서/up_column_dictionary_ko.csv (기본)
- 문서/column_dictionary_archive/up_column_dictionary_ko_YYYY-MM-DD.csv (이관본)

생성 규칙:
- build_daily_report.py 실행 시 문서/up_column_dictionary_ko.csv가 없을 때만 자동 생성

## 7) 자주 발생하는 질문

Q1. 최종매수후보가 왜 하루 만에 바뀌나?
- breakout_20d_high on/off 전환, 거래량 정상화, 상대순위 재정렬 때문인 경우가 많다.

Q2. diff 파일이 없는 날이 있나?
- 전일 valuation_report 파일이 없으면 diff 파일은 생성되지 않을 수 있다.

Q3. 컬럼 딕셔너리 파일이 output에 왜 없나?
- 정책 변경으로 문서 폴더 고정 파일(up_column_dictionary_ko.csv)로 관리한다.
