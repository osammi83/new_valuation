## 📋 문서 목차 & 역할

### 1️⃣ **신규_개발_재구축_매뉴얼.md** (필독)
**누가 봐야:** 개발자, 시스템 관리자  
**언제:** 처음 시작할 때, 재설치/이전할 때  
**내용:**
- UP 시스템의 전체 구조 (KR과 비교)
- 최신 확정 정책 (DART 우선 EPS, REIT-only 제외, 연속형 점수)
- 재구축 절차 (환경변수/실행/검증)
- 일일 산출물 체계 (기본 + 확장)
- 트러블슈팅

**🎯 추천:** 처음 1회 정독, 이후 필요시 참고

---

### 2️⃣ **컬럼_딕셔너리_상세.md** (핵심 자료)
**누가 봐야:** 모든 사용자  
**언제:** 리포트를 읽을 때, 특정 컬럼이 뭔지 모를 때  
**내용:**
- 모든 컬럼의 한글명, 영문명, 설명
- 도메인 값 (범위, 선택지, 예시)
- 계산식 상세 설명
- 파일별 컬럼 구성
- 데이터 소스 & 갱신 주기

**🎯 추천:** Bookmark 해두고 자주 참고

---

### 3️⃣ **파일_해석_가이드.md** (실무용)
**누가 봐야:** 투자자, 트레이더, 분석가  
**언제:** 매일 아침, 리포트를 읽을 때  
**내용:**
- 각 CSV 파일의 역할 & 읽는 법
  - `universe.csv`: 분석 대상 800종목
  - `assumptions.csv`: 수동 입력 파라미터
  - `eps_cache.csv`: EPS 캐시
  - `상세리포트_*.csv`: 상세 리포트
  - `관심종목요약_*.csv`: 추천 관찰 목록 ⭐ (가장 중요)
  - `진입후보요약_*.csv`: 진입 후보
- 시나리오별 활용 예시
- Python/엑셀 분석 예제
- 트러블슈팅

**🎯 추천:** 매일 아침 10분 체크, 새 컬럼 배울 때

---

### 4️⃣ **컬럼_딕셔너리_도메인_값.csv** (참고 테이블)
**누가 봐야:** 모든 사용자  
**언제:** 컬럼 값의 범위/선택지가 헷갈릴 때  
**내용:**
- 표 형식 컬럼 정의 (45개 컬럼)
- 각 컬럼의 domain values (도메인 값)
- 실제 예시

**형식:** CSV (엑셀로도 열 수 있음)

**🎯 추천:** 빠른 참고용, 엑셀로 필터링 가능

---

### 5️⃣ **자동화_운영_매뉴얼.md** (운영 가이드)
**누가 봐야:** 시스템 관리자, DevOps  
**언제:** 스케줄러 설정할 때, 매일 오전 운영 때  
**내용:**
- 로컬 수동 실행과 GitHub Actions 운영 자동화 분리
- DART 키, Google Drive 서비스 계정, KRX 로그인 등록
- GitHub 기반 일일 생성/백필/업로드 흐름
- 수동 실행 방법과 트러블슈팅

**🎯 추천:** 설정 1회 + GitHub 운영 기준 참고

### 6️⃣ **Google_Drive_설정_가이드.md** (연결 가이드)
**누가 봐야:** 시스템 관리자, 운영 담당자  
**언제:** Google Drive 연결할 때, 서비스 계정 만들 때  
**내용:**
- Google Cloud 프로젝트 생성
- Drive API 활성화
- 서비스 계정 JSON 발급/공유
- 로컬 실행용과 GitHub Actions 실행용 설정 분리
- 검증 명령과 트러블슈팅

**🎯 추천:** Drive 연결 시 먼저 읽기

### 7️⃣ **Google_Drive_설정_완료_체크리스트.md** (점검표)
**누가 봐야:** 시스템 관리자, 운영 담당자  
**언제:** 설정 후 확인할 때  
**내용:**
- 체크리스트 형태의 완료 확인
- 설정 파일 수정 여부 확인
- 테스트 실행 및 Drive 업로드 확인

**🎯 추천:** 설정 직후 체크용

## 🎯 사용 시나리오별 추천 문서

### 시나리오 1: 새로 시작하는 사람
```
1. 신규_개발_재구축_매뉴얼.md (전체 이해)
2. 자동화_운영_매뉴얼.md (초기 설정)
3. 컬럼_딕셔너리_상세.md (북마크)
```

### 시나리오 2: 매일 아침 결과 확인
```
1. 파일_해석_가이드.md (관심종목요약 읽는 법)
2. 컬럼_딕셔너리_상세.md (특정 컬럼 정의 확인)
3. → 상위 10개 종목 확인 후 매매 결정
```

### 시나리오 3: 수동 파라미터 조정 (월 1회)
```
1. 파일_해석_가이드.md (assumptions.csv 설명)
2. 컬럼_딕셔너리_상세.md (eps_growth_3y_pct, target_pe_* 등)
3. → assumptions.csv 수정
4. → 다음 리포트에서 결과 확인
```

### 시나리오 4: 시스템 장애 발생
```
1. 자동화_운영_매뉴얼.md (트러블슈팅)
2. → 문제 분류 및 해결
3. 신규_개발_재구축_매뉴얼.md (백그라운드 이해 필요시)
```

### 시나리오 5: 리포트 심화 분석
```
1. 파일_해석_가이드.md (파일별 역할)
2. 컬럼_딕셔너리_상세.md (모든 컬럼 설명)
3. → Python/엑셀로 고급 분석
```
