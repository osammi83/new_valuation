# 추가 개선 백로그

- `run_pipeline.py` 단계 번호를 단순화하고, 모듈 단계/검증 단계를 더 명확히 분리한다.
- `build_daily_report.py`의 남아 있는 중복 책임은 전체 개발 종료 후 추가 분리한다.
- `validate_csv_contracts.py`는 최신 파일 기준으로 이미 바뀌었지만, 향후 산출물 manifest 기반으로 더 엄격하게 통합할 수 있다.
- Windows 파일 잠금 시 `_locked_*.csv`를 남기는 정책은 운영이 안정화된 뒤 정리한다.
- `publish_to_drive.py`와 기존 업로더의 명칭/진입점 일관성을 후속 정리 대상에 둔다.
